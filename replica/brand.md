## Trademark warning (important)

"DhandhaAi" is close to the original's name "Dhanda". Similarity of name in the
same product category is a real trademark/confusion risk, regardless of clean
code. Before charging money, the owner should:

1. Search Nepal's Department of Industry trademark register and India's IP
   India register for "Dhanda" / "Dhandha Ai" in classes 9, 35 and 42.
2. Check domain availability (e.g. dhandhaai.com.np / .com) and app-store name
   availability without implying affiliation with the original.
3. If clearance is shaky, rename - renaming is cheap now (one string + logo
   tile) and expensive after users arrive. Candidate directions (unresearched,
   check before use): names around "pasal" (shop), "bechaan"? No - do proper
   searches; do not adopt a suggestion from this file unchecked.
4. Get a local lawyer's view if revenue is planned. This file is not legal advice.
